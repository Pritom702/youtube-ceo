# Analytics drop zone

Drop YouTube Studio numbers or screenshots here, one file per channel per date,
e.g. `larry_2026-08-10.md`, `rankedchaos_2026-08-10.md`. The CEO reads these to
decide the next briefs and to update the pace tracker in `../strategy/north_star.md`.

The two pipelines also have their own paste files the CEO reads:
- `T:\Youtube Shorts 2\analytics\PASTE_ANALYTICS_HERE.md`
- (Pipeline 1 analytics: paste here or in the Shorts project.)

Fastest useful format per channel:
```
Date:
Subscribers:
Views last 7d / 28d:
Per-video: | Title | Posted | Views | Avg % viewed | Likes | Comments |
Notes: (a spike, a flop, a comment theme)
```
Avg % viewed (retention) is the metric the CEO acts on first.
