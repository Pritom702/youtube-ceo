# The YouTube CEO

The brain that runs three YouTube Shorts channels through two pipelines. Every
session that touches the channels reads `CEO.md` first. Both pipelines take a
CEO brief before generating and submit output for CEO review before publishing.

## Talk to the CEO
- **`/ceo`** — start a CEO session (loads the brain + today's state).
- "Make today's videos" · "What should I post?" · "Review these" · paste analytics.

## Map
```
T:\Youtube CEO\
├── CEO.md                    <- the brain: mission, chain of command, decisions, review checklist
├── SUBMIT_FOR_REVIEW.md      <- how pipelines submit shorts for approval
├── channels\                 <- dossier per channel (1 Larry Wheels, 2 Ranked Chaos, 3 TBD)
├── pipelines\                <- how each pipeline works + CEO integration
├── strategy\
│   ├── north_star.md         <- 90-day pace math + tracker
│   └── playbook.md           <- what's working now (grows daily)
├── research\
│   ├── LEARNINGS.md          <- append-only daily YouTube learnings
│   └── daily\                <- dated research reports
├── daily\                    <- daily briefs + end-of-day reports
├── reviews\                  <- CEO verdicts per submitted short
└── analytics\                <- analytics snapshots the owner drops in
```

## The loop
Brief → Generate (to spec) → Submit → Review (checklist) → Verdict (approve/revise/
reject) → Learn (analytics feed the next brief). See `CEO.md`.

## Mission
Each channel: **10M views + 1,000 subs in 90 days** (by ~2026-10-24). Get every
channel monetized. Every day's shorts beat yesterday's.
