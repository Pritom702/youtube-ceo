# North Star — the 90-day pace math

**Goal per channel:** 10,000,000 valid public Shorts views + 1,000 subscribers.
**Clock:** Day 0 = 2026-07-26. Deadline ≈ **2026-10-24** (90 days).

## The daily math
- 10,000,000 / 90 = **111,000 views/day per channel** (even pace).
- Three channels = 333,000 views/day across the operation if all even.

| Cadence/channel | Videos in 90d | Views/video needed |
|---|---|---|
| 1/day | 90 | 111,000 |
| 2/day | 180 | 55,600 |
| **3/day** | **270** | **37,000** |
| 4/day | 360 | 27,800 |
| **6/day** | **540** | **18,500** |

Volume is the single biggest lever. At 1/day the target is effectively
unreachable. Recommended ramp: **2–3/day weeks 1–2** (prove the format beats
current best), **4–5/day weeks 3–12** using Part 2 / Part 3 series on winners.
Don't jump to 6/day cold — small channels get impression-throttled, and a QC
fail is worse than no post.

## Subscriber engine
1,000 subs = one clear reason to subscribe, repeated: recognizable format +
series ("Part 2/3") on proven topics + a spoken/on-screen "follow for part 2".
Track sub velocity weekly; if flat while views climb, the *reason to subscribe*
is missing — fix the format, not the topics.
